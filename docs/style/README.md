# Style findings

Conclusions from the `/watch` development skill (`.claude/skills/watch/`): what reference videos do, and which ClipCrow
lever (caption style, push-in, framing, text behind the speaker, branding, planner options) would reproduce it. This folder is
documentation for the developer. It is not part of the product and not shipped in the image.

- `reference-log.md`: one entry per watched video (slug, link, creator, date, takeaways).
- Raw material (downloaded footage, frame sheets, analysis) lives in `references/`, which is git-ignored.
